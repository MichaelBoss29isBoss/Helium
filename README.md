# Helium
A vey basic redirect for early or just chapter 1 versions of Fortnite.

This redirect is pretty much a tiny tiny fork of: https://github.com/itzkera/Redir  it is what it is :P

## Configure & Build from source

**To Configure:** Go to **`Public/opts.h`** and change `sBackendUrl` to your backend url then change `sCurl_Easy_Setopt_SIG` to your Curl_easy_setopt  signiture (You will need a IDA dump for this).

**To Build:** Open **`Helium.slnx`** in Visual Studio 2026 then change the release type from `Debug` to *`Release`* then hit *Ctrl+Shift+B*.

then you are all set skidda!
